# 界面与交互约束

本文件保留已确认的产品交互。标尺与角色见 [设计系统](design-system.md)，尺寸事实以共享令牌和组件 CSS 为准；调整交互时同时维护文档与验证。默认几何不能遮挡错误、阻断键盘操作或妨碍放大文字。

## 认证入口

- 桌面以整个窗口作为单任务画布，单列、居中、低噪声；品牌在同一稳定视图中只出现一次，不叠加营销分栏、装饰性徽章或额外玻璃卡片。
- 登录与注册始终有明确入口。纵向胶囊主操作最多两个；一次性授权码保留明确的文字入口及独立输入步骤，说明获取来源，作为深链失败后的恢复路径。
- 网页登录与注册复用同一套字段 DOM：邮箱、密码、模式专属槽、反馈槽和提交槽保持顺序与坐标。专属内容在槽内变化，异步状态在原按钮内更新；长错误可以向下扩展。
- 浮动标签只用于网页登录、注册等账号凭据入口的邮箱与密码字段，在焦点、内容与自动填充时正确切换，不关闭 autocomplete 规避样式。一次性授权码、验证码、用户名和安全任务字段使用普通占位文案与可访问名称，不播放标签上移。输入框聚焦改变既有边框；其他键盘控件保留可见焦点，不能因视觉偏好删除焦点提示。
- 字段图标与尾部密码动作有固定槽位。光学校正只改变槽内墨迹，不改变文字起点或命中区域；每个密码字段独立管理显示状态。
- Google、通行密钥等入口使用提交按钮下方的紧凑圆形槽，不增加全宽胶囊和“或”分割线。图标按钮有名称与状态反馈；无法使用的方式不能悄悄消失导致重排。
- 首次进入认证页不抢输入焦点。发送验证码等明确动作后可进入下一必填字段；用户打开模态框时焦点必须进入模态范围。
- 注册不要求邀请码或姓名，内部用户标识由服务端生成。验证码仅在用户发起发送后投递；服务端投递失败不能被显示为成功。

## 敏感操作卡片

- 安全页面提供入口，验证与实际操作在同一卡片的步骤内完成；成功后关闭并刷新状态。可由行状态表达的结果不再追加重复的成功文案。
- 任务卡共用顶部操作带、标题、内容、反馈与底部动作骨架。普通步骤保持锚点；长错误、窄窗口、短窗口与字号放大允许换行和滚动。头像选择与裁剪是不同内容类型，可按真实内容改变高度。
- 返回在顶部左侧，关闭在右侧；步骤历史按实际访问路径返回，不绕过必要的验证。卡片正文居中，输入内容左对齐；动作区固定在内容之后，取消在左、推进在右。窄屏保持 DOM 与键盘顺序，通过 CSS 排布。
- 默认邮箱验证由用户手动发送；方法列表只显示实际配置且本次操作允许的方法。通过验证后继续原动作，授权过期或已经消费则重新验证。
- 修改密码默认使用当前密码路径；“用其他方式修改？”直接进入方法列表，保留返回原路径的入口，不能先指定邮箱再套一层方法选择。
- 开启双重认证的二维码保留 quiet zone，恢复码便于复制并完整显示；库要求的密码步骤与服务端操作授权都必须完成。
- 验证器二维码固定黑码白底，不继承深色主题的文字色；通过二维码库的公开选项控制几何，不裁改内部 SVG 结构。
- 关闭卡片、切换步骤或发起新的凭据动作时，清理请求与计时器。系统凭据面板有真实取消和超时恢复；迟到结果不得改变后来打开的卡片。
- 验证码的已发送、等待与冷却按收件人保存；只有投递成功才开始冷却。修改地址或返回旧地址不能带入错误状态或清除已有冷却。
- 头像点击与“选择图片”复用选择入口；裁剪允许重选，缩放有明确名称与说明，取消、选择和保存各自表达真实动作。

## 动作语义

实体按钮复用两端共享的 `Button` / `ButtonLink`，使用同一个 `variant` 协议。先判断动作，再选角色；悬停和按下保持几何，禁用统一使用中性状态。

| 角色                    | 用途                         | variant          |
| ----------------------- | ---------------------------- | ---------------- |
| Secondary / Cancel      | 取消、关闭、放弃             | `outline`        |
| Utility                 | 查看、管理、修改入口         | `secondary`      |
| Primary                 | 当前任务的保存、继续、完成   | `primary`        |
| Brand / Special Primary | 明确的品牌、连接、授权主操作 | `accent`         |
| Destructive Secondary   | 危险入口、可恢复的安全降级   | `danger`         |
| Destructive Primary     | 删除、退出等最终确认         | `danger-primary` |

退出登录、退出单个设备和退出其他设备均先打开确认卡片，不使用按钮变字后限时再点击的方式；确认后显示占用，失败留在同一卡片中重试。确认卡片复用共享视图，不能以此代替服务端授权。

一个操作区域只有一个主要推进动作。危险入口使用浅红背景与红色文字，最终确认使用系统红填充与白字；不能按“删除”二字机械选色。普通保存不使用品牌蓝。填充、文字、图标与焦点色分别使用对应令牌，常态系统红与增强对比度模式的配对约束见工程与设计维护规范。

胶囊按标签宽度分为 2、4、6、8 字档，奇数字向上取偶数档，超过 8 字继续递增；字形按 grapheme 计数，英文按近似字宽估算。默认宽度 = 标签档位 × 该按钮字号 + 两侧内缩，文字放大同步扩大。`ActionGroup` 将任意数量的同组按钮统一为最长稳定标签档，横排与竖排都保持等宽；占用或复制反馈使用 `sizeLabel` 保持原标签档。标签不换行，窄空间由动作区域重排承接。

同一认证列中的纵向登录与注册按钮、表单提交、验证方式列表可明确填满所属列，属于相同的全宽角色，不以标签档限制宽度。紧凑操作两端共用高度与字号；粗指针设备扩大触控目标，窄手机下同组动作纵向填满可用列，顺序与 DOM 一致。

纯文字动作复用 `text-action`：默认透明，细指针悬停出现轻量语义底色，按下与键盘焦点可见，禁用不响应悬停；轻量导航使用 neutral 文字角色。字段内发送动作保留固定槽与分隔线，但提供同类背景反馈。侧栏导航、菜单项目、分段选择和开关使用所属控件语义，不机械套文字按钮。

## 桌面窗口与侧栏

- 原生红黄绿、窗口圆角与全屏 Space 交给 Electron/AppKit，不在 Renderer 仿制或用猜测的半径遮罩窗口；自定义矩形、正圆与胶囊按各自类型表达曲率。
- AppShell 独占侧栏宽度与开合状态。像素偏好不随窗口放大或全屏按比例变化；主区域通过 `minmax(0, 1fr)` 吸收余量。
- 子页面只依赖父容器，不以全局视口或侧栏宽度计算内容列。列宽使用上限与流体宽度，在主区域内居中；CSS 能表达的布局不引入测量状态。
- 分隔线使用 Pointer Events、pointer capture 与 `role="separator"`。键盘支持方向键、Shift 快速步进、Home / End；拖动只更新内存，结束后持久化。
- 宽侧栏第一次拖动仅收缩到最小宽度；松手后重新从最小宽度拖动才可隐藏。阈值与默认宽度由手势模块提供；双击恢复默认宽度，按钮与拖动复用开合命令。
- 边缘唤出是临时预览，指针离开后收起；明确点击才固定展开。拖动直接跟随指针，不套延迟动画；开合时内部保持正常宽度，由外层裁切。
- 窗口 resize 不启用常驻布局 transition；面板动画只对应用户的开合与预览动作。不使用 `transition: all`。
- 标题拖拽区域排除交互控件，不为聊天另留实体空白标题行。最小窗口、原生全屏、最大化与恢复时都保持按钮和内容可用。

## 设置与聊天

- 设置、账号等页面先确定内容列，标题与卡片共享左右边线；卡片填满所属列，不再自行指定宽度。弹窗按编辑、任务、列表角色选档，窄窗口保留安全留白并收缩。
- 账号总览复用 `AccountOverview`：两端同为「个人信息（头像身份行、用户名行）→ 安全 → 设备与登录」，名称统一为「账号」。客户端查看设备打开列表卡片，网页进入独立页面；安全设置通过系统浏览器执行，保留真实载体边界。
- 网页账号页保留顶部返回导航槽，即使没有返回按钮也不删除占位；账号与登录与安全等子页面的标题保持同一纵向起点，导航槽随触控目标和字号自然增高。
- 用户名编辑使用独立弹窗，两端共用视图、校验与保存生命周期；身份卡保持稳定高度。字符按 Unicode code point 计数，字段的 UTF-16 长度上限不能误删可用字符。
- 设置结构复用 `SettingsPanel → SettingsGroup → SettingsRow`，分组和行委托共享 `PanelGroup` / `PanelRow`，外壳使用 `PanelCard`。标题、分组、卡片、分隔线与行内缩共用样式；没有右侧控件时不添加空占位。
- 账号、设置、设备和凭据等紧凑面板的标题与辅助文字各占一行，不换行；超宽时复用 `TruncatedText` 显示省略号，操作与徽章保持固定槽位，不因文案变长增加面板高度。主题预览等丰富内容仍按自身类型排版。
- 省略只影响视觉展示，DOM 与悬停提示保留完整文字，不增加额外的 Tab 停靠点。正文、错误和完整任务说明不套紧凑行规则。
- 字号档只改变文字标尺，不另建每档的侧栏、按钮、卡片圆角和间距。页面不另写重复的行几何或分隔线。
- 主题预览是富控件行，按设置内容区的宽度切换上下排布，并允许选项自然折行；不能用窗口断点猜测侧栏占用后的剩余空间。原生窗口最小尺寸由 Main 管理，Renderer 不重复锁死页面最小尺寸。
- 空状态、正文、错误条与 composer 共用 `--chat-content-max-width`。窗口变宽增加留白；用户气泡在列内另设短文本约束，代码按现有策略折行，表格保留局部原生横向滚动，不撑宽页面。
- 图标式复制操作成功后只把图标换成对号，不追加可见状态文字或更换悬停说明；保留读屏反馈。带文字的胶囊复制按钮可以在原文字位置显示“已复制”。
- composer 保持悬浮胶囊与底边锚点，多行向上增长且有上限。左右操作对齐底部输入行，单行文字通过行盒与控件高度计算居中；发送或清空后恢复单行高度。
- 输入框与消息编辑器共用键盘提交规则。输入法组词期间 Enter 和 Escape 交给输入法，不提交或取消编辑；换行和发送偏好只在组词结束后生效。
- 对话态消息区通过末尾 padding 让最后消息滚过悬浮 composer。只有用户仍在底部附近时跟随流式输出；主动向上滚动后保留位置，跳到底部按钮跟随 composer 高度并表达生成状态。
- 跳到底部遵循 reduced motion，关闭动画时立即到达目标；切换对话清理旧滚动计时器。Tab 在模态首尾循环时允许浏览器把目标控件滚入可见区域。
- “新建对话”只选择空白草稿，首次有效发送才创建对话、首条消息与临时标题；未发送草稿不出现在列表。打开认证画布保留草稿，账号切换则清理原账号数据。

## 滚动与设备显示

- 桌面隐藏视觉滚动条；网页允许克制的页面级滚动条，内部滚动条隐藏。策略留在各端基础样式，不进入共享主题以免误伤另一载体。
- 保留浏览器原生 overflow、滚轮、触控板、键盘、滚动锚定与焦点滚入可见区域。隐藏滚动条不能改成 JS 滚动模拟，也不能造成横向跳动。
- 可滚动列表可在边缘自然露出下一项；不增加装饰箭头、闪烁或“向下滚动”文案。聊天正文不必露出半条消息。避免多层可见滚动条，长内容不能为了隐藏滚动而无限撑高弹窗。
- 设备识别只调用 contracts 的 `normalizeSessionClient` 与 `formatSessionClient`；时间只调用 `formatSessionActivity`。元数据、Velin token、CLI、已知嵌入宿主、普通浏览器依次识别，最后明确落到未知客户端。
- 客户端设备卡片的加载、空状态和列表共用稳定的阅读区域，更多设备在区域内滚动，不先显示矮卡片再替换。只有当前设备、尚未读到设备或有操作正在执行时，退出其他设备禁用且显示中性灰；权限或服务端拒绝则保留明确错误和恢复路径，不能无反馈。
- 设备读取失败提供重新读取入口，不能继续显示加载状态。退出期间其他退出动作不可提交；操作成功但刷新失败明确说明部分结果，不能恢复已退出的设备行。错误和恢复动作允许增加任务弹窗高度，窄窗口动作自然折行。
- `Electron` 不能单独证明这是 Velin，Chrome token 不能覆盖嵌入宿主；版本、IP、登录方式等底层字段不进入默认两行列表。UA 与 client metadata 只用于展示，不参与授权。

## 修改与验证

新增规则应说明适用角色、事实来源与可检查行为，不能只记某次截图的修补参数。布局变化检查最小窗口、长内容、字体放大、键盘、两种主题和 reduced motion；未执行的检查在验证记录中明确列出。
